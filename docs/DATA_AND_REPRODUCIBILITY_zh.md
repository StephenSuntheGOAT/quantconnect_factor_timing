## 宏观 CSV 与时间

三列为 `period,available_at,value`，列顺序不限。无时区时间按纽约时间理解。
本包 `available_at` 人为设定为观测月后第 2 个月的 1 日 00:00，并不是实际公告时点。
例如 2026-09 的最后一条记录标为 2026-11-01 可用；这是规则生成的标签，不是当日
已发生的公告。回测只读取历史信号截止日可用的行，但这个延迟规则无法去掉历史修订
偏差。真正的 point-in-time 数据应为每一次发布/修订单独记录实际可用时刻。

TB3MS 的 value 单位是年化百分数，如 3.94 表示 3.94%，不是 394%。代码用前月末
可知的利率，按当月天数将年化报价近似换算成月收益，用于训练中的超额收益。
账户余资实际投资 BIL；BIL 收益与此训练用无风险近似不是同一序列。

SPY 预测输入是上个完整月末的 `log(过去 12 个完整月现金股息 / 原始价格)`。
训练收益按原始价格和现金股息构造，避免复权价格再加股息。仅针对无拆股的固定 SPY
实现，遇到拆股停止。行情在 QuantConnect 环境中获取，不在 Python 源码内嵌入。

## 没有的数据与结果

- 没有单独保存完整 SPY/BIL 分钟、日线和股息历史；原始 JSON 中的图表点和订单不能替代行情数据库。
- 没有原论文/研报使用的 PMI 历史发布版本、50 异象收益及对应估值面板。
- 没有已完成的 HML/PC1 原样复现结果；paper_research.py 和 schema 只是已实现的研究接口。
- 没有逐月预测值、每期回归系数或完整文本日志文件；只能恢复导出中已有的统计及截图文字。
- 没有每次云端运行的源码逐字快照、完整 Python 依赖或数据供应商版本。保存的是最新源码和 JSON 中记录的运行参数、LEAN 版本。
- 没有额外的稳健性网格搜索、独立留出样本或显著性通过证据；未给不存在的实验填写结果。

## 本地能够完整重建的内容

1. `python tests.py`：执行 26 项数值、时间对齐、PCA、载入器和仓位逻辑测试。QC 服务被最小模拟，不是新的 LEAN 云端回测。
2. `python scripts/summarize_results.py --plots`：离线读取 JSON，重建汇总 CSV/Markdown、净值/仓位/订单/回撤 CSV 和总览 PNG。
3. `python scripts/verify_archive.py`：校验交付时的 SHA-256、参数与原导出一致性、净值收益恒等式、重复文件和 C 重跑一致性。

如修改文件后再运行 hash 校验，失败意味着交付快照发生变化，并不自动意味着交易
逻辑错误。manifest 是交付时快照，不是自动随修改更新的测试预期。

## 必须在 QuantConnect 或 LEAN 数据环境中完成的内容

重新运行 main.py 需要 SPY/BIL 行情权限和两个外部 CSV。仅执行 `python main.py`
不能启动 QCAlgorithm。固定对照不读取宏观 CSV，也不需要 240 个月训练历史。

所有非 fixed 运行均同时拟合四种预测模型；参数 model 决定用哪个模型交易。所以 C
和最后一次回测能显示三个模型的 OOS R²。n=71 是当前入口延后评分导致，不是遗漏
了 72 次月度交易。最后一个月的收益未在下一次调仓评分。

平台 JSON 中的 `outOfSampleDays` 等配置字段只是保存的元数据，不能替代研究中真实
未被查看过的独立测试集。第一轮 LEAN 为 v2.5.0.0.18209，后续为 v2.5.0.0.18215。

## 结果字段说明

summary.csv 中名称带 `_fraction` 的收益、仓位、波动率均为小数；例如 0.124 表示
12.4%。Sharpe、Beta 无单位，费用/净值为美元，最大回撤记正幅度；drawdown CSV
则记录相对于高点的负值。空白统计是原导出未给出，不能当作 0。

平均仓位取 72 个月度图表目标的简单平均，既不是实际每日持仓的平均，也不是 Beta。
裁剪后的目标等于 99% 的次数与运行时按裁剪前目标计算的 cap touches 概念不同；
本次数据中数值相符，不据此把二者一般化为相同指标。

净值图表是 OHLC 数据，整理脚本读取 CLOSE（第 5 个值），保留原时间戳。导出图表
可能经过采样，不能从中宣称重建分钟收益或重新精确计算平台 Sharpe。Sharpe、CAGR、
手续费和最大回撤均直接使用 statistics 字段；runtimeStatistics 的 Net Profit 是平台
显示的金额字段，不能替代 statistics 中累计收益百分数。基准 CSV 仅重排原基准图表，
未把它宣称为包含相同费用和股息处理的可交易 100% SPY 对照。
