# 实验、调参和实现修正记录

整理日：2026-10-29（Asia/Shanghai）。这是一份根据当前代码、用户导出的回测 JSON、
日志截图及已确认讨论整理的研究记录。精确参数以 `configs/parameters/` 和原始 JSON
为准。没有恢复到的旧源码、失败运行和逐月预测，均未补造。

## 1. 研究问题与初始选择

研究问题是：估值信号的预测作用是否随着经济状态改变；加入“估值 × 宏观状态”后，
能否在交易成本和持仓调整限制下改善组合表现。原研报还讨论 HML、PC1 等因子。
当前实际交易实验先使用 SPY 股息价格比与 CFNAI，闲置资金配置 BIL。

统一设置为 2020-01-01 至 2025-12-31、初始资金 100 万美元、240 个完整月度训练对、
滚动窗口、gamma=3、lambda=300、VAR 特征根上限 0.995、SPY 上限 99%、
1bp 成交滑点和代码指定的 IB 手续费模型。除 JSON 中显式设置的参数外，以上是最新
源码的默认值，无法用它们替代当时云端源码的逐字版本证明。

## 2. 实现修正过程

| 遇到的问题 | 最终处理 | 留下的验证或文件 |
|---|---|---|

## 3. 第一轮：四模型比较

| 记录 | model | 变化 | 目的 |
|---|---|---|---|
| model_mean | mean | 只使用历史均值收益预测 | 动态组合的预测基线 |
| model_linear | linear | 加入估值 x | 看估值是否提供信息 |
| model_bivariate | bivariate | x + 宏观 s | 检查加法经济状态信息 |
| model_interaction | interaction | x + s + x*s | 检查状态依赖的估值作用 |

实际云端运行顺序为 interaction、mean、linear、bivariate；为了读表方便，汇总表按模型
复杂度排序。具体 UTC 时间保存在 `results/exported_metadata.json`，没有把上传时间
当成回测开始时间。四次导出均对应 2020—2025 样本。

linear 的 Sharpe=0.740、年化收益=12.400%、最大回撤=11.4%，在本组模型中表现较好；
interaction 的累计收益更高，但最大回撤为 26.0%，平均月度 SPY 目标约 83.68%，
而 linear 约为 54.01%。因此不能只按累计收益判断交互项更有效。

截图记录的共同样本一步预测 OOS R²：linear=-0.7606%、bivariate=-22.3068%、
interaction=-0.6183%，n=71。负值表示预测平方误差比历史均值更大；这些数字不是组合
投资回报率。较好的风险收益指标不自动证明预测误差改善。

## 4. 第二轮：A / B / C 对照与诊断

| 文件 | 实际参数 | 实验目的 | 注意点 |
|---|---|---|---|
| A.json | model=fixed, fixed_weight=0.55, fixed_entry=immediate | 一开始建立固定 55% SPY，每月再平衡 | 其他资金主要配置 BIL |
| B.json | model=fixed, fixed_weight=0.55, fixed_entry=gradual | 使用动态策略相同的调整速度，从空仓靠近 55% | 每月继续按实际 SPY 权重平滑调整 |
| C.json | model=interaction；默认 economic_constraints=true | 重跑交互模型并输出诊断 | fixed_weight=0.55、fixed_entry=gradual 在该模式不生效 |

55% 是看过 linear 的样本平均仓位后选出的近似对照；不是事先设定的独立检验，也不
构成精确的波动率或 Beta 匹配。B 的平均月度目标约为 47.99%；受实际仓位漂移影响，
其某些月的目标可能高于 55%，并非代码失效。

A 年化 9.566%、Sharpe 0.435、回撤 19.2%；B 年化 8.872%、Sharpe 0.482、回撤 13.9%。
linear 在已看过的样本中高于这两个对照，但尚未排除所有暴露、路径或数据修订影响。

C 与第一轮 interaction 的组合统计和关键图表完全一致。C 的诊断显示：

- 72 次调仓，平均 SPY 目标 83.6757%，34/72 次触及 99% 上限；0 次触及零仓位。
- interaction 因经济系数符号筛选而回退历史均值 52/72 次；约 72.2% 的拟合未直接使用该次交互回归系数。
- linear、bivariate 的回退次数均为 0/72；三个非均值模型的 VAR 稳定化均为 1/72。
- 拟合统计含最后一次未评分预测，所以 72 次拟合与 71 个预测评分并不矛盾。

## 5. 第三轮：关闭经济约束的消融

在 C 的参数基础上增加 `economic_constraints=false`，其余导出的参数不变。
原文件名为 `Ugly Fluorescent Pink Snake.json`；带 `(1)` 的下载与其逐字节相同，
不是第二次独立实验。归档时只替换文件名中的空格，映射见 `results/source_inventory.json`。

| 指标 | C：有符号约束 | Snake：无符号约束 |
|---|---:|---:|
| 累计收益 | 115.912% | 68.023% |
| 年化收益 | 13.676% | 9.027% |
| Sharpe | 0.577 | 0.543 |
| 最大回撤 | 26.0% | 11.5% |
| 平均月度 SPY 目标 | 83.68% | 38.43% |
| 回退历史均值 | 52/72 | 0/72 |
| 上限触及 | 34/72 | 0/72 |
| 零仓位触及 | 0/72 | 5/72 |
| interaction 的预测 OOS R² | -0.6183% | -20.7547% |

关掉符号约束后，回退消失、风险敞口下降，但预测误差指标明显变差，收益也降低。
这说明当前 interaction 的历史表现很受筛选规则和最终仓位影响，现有结果不足以证明
交互项带来了稳定预测优势。
